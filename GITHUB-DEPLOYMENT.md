# DUA Medical Store

Live app: https://dua-medical-store.saadcr224.chatgpt.site

This repository mirrors the app source. Production runs on ChatGPT Sites with its managed D1 database. Database records and secrets are not stored in this repository.

Changes requested in the original ChatGPT conversation should be committed to this repository and published through Sites. A GitHub push alone does not deploy to Sites; no automatic GitHub-to-Sites deployment hook is configured.
